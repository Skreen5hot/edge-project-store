# Contract examples

Synthetic project folders for [`../spec/edge-project-contract.md`](../spec/edge-project-contract.md). Each `EX-nn`
folder holds `project/` (the folder to evaluate) and `expected.jsonld` (the ProjectReport a conforming reader must
produce, byte for byte). Generated by [`../tools/gen-examples.mjs`](../tools/gen-examples.mjs); do not edit by hand.

| Example | What it shows | Rules |
|---|---|---|
| [EX-01](EX-01-empty-project/) empty-project | A project with no stages yet. | R-P2, R-E4, R-E5.7 |
| [EX-02](EX-02-chain-ok/) chain-ok | Source → normalized → SDD, all current; the SDD is pipeline-ready. | R-E3–R-E8 |
| [EX-03](EX-03-source-added/) source-added | A source file added after normalization: the normalized schema and the SDD are out of date, recursively. | R-E4, R-E6 (SOURCE-CHANGED, UPSTREAM-OUT-OF-DATE) |
| [EX-04](EX-04-source-removed/) source-removed | A source file (and its record) deleted after normalization. | R-W7, R-E6 (SOURCE-CHANGED) |
| [EX-05](EX-05-source-altered/) source-altered | A source file edited in place: an integrity error, and it is no longer a member. | R-E3 (E-INTEGRITY), R-E4, R-E6 |
